# Sandalia Gestionale

Portale dello Studio Sandalia (contabilità, bilancio XBRL, dichiarazioni, F24) nella versione web.
I dati non sono in questo repository: si trovano nel progetto Supabase dello Studio e sono accessibili
solo agli utenti iscritti tra i membri. Il sito non contiene chiavi: indirizzo del progetto e accesso
si inseriscono dal portale e restano nel browser di ciascun dispositivo.
